Python Finance Manager

Motivation:
An effective and simple way of tracking personal finance using Python.

Data Description:
The project uses a plain text file (.txt) to manage personal transactional data, separated by the pipe delimiter (|).
Structure: Date | Type | Amount | Description
The file is created once, and data is manipulated in the same file as per the needs of the user.

How to use?
Ensure the availability of Python 3 on your computer to use this application. Make sure the PythonFinanceManager.py file is saved locally on your computer before running. Double click to run the file. It opens the program in windowed mode. Follow the on-screen instructions and pop-ups to manage your finances using the project.

Notes:
The program is a simple personal finance tracker that works by creating a text file on your computer and storing transaction data fed by the user. It uses Tkinter GUI to display the data in an easy-to-understand and user friendly manner. It incorporates various error handling techniques to minimize error and accidental data loss. It can be used to maintain a simple, effective and useful transaction sheet.
